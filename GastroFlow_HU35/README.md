# Gastroflow - HU-35 Gestión de propinas y descuentos

Implementación de la Historia de Usuario HU-35 del sistema Gastroflow utilizando JavaFX, Maven y PostgreSQL.

## Descripción

Esta funcionalidad permite al Cajero gestionar propinas y descuentos durante el proceso de pago de una cuenta, garantizando el cálculo correcto del total y el registro de la información del pago.

## Funcionalidades principales

- Consulta de pedidos mediante número de pedido.
- Visualización de subtotal, impuestos, descuentos, propina y total.
- Agregar, modificar y eliminar descuentos.
- Solicitud de motivo al aplicar descuentos.
- Agregar, modificar y eliminar propinas.
