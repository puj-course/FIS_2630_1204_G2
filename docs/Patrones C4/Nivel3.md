# Diagrama de Componentes C4 – Nivel 3

## 1. Descripción general

El diagrama de componentes C4 de **GastroFlow** presenta la organización interna del sistema, identificando los principales componentes de software, sus responsabilidades y las relaciones existentes entre ellos.

Este nivel permite comprender cómo se estructura la aplicación y cómo interactúan sus diferentes componentes para gestionar las operaciones del restaurante.

## 2. Diagrama de componentes

A continuación, se presenta el diagrama C4 de Nivel 3 correspondiente a GastroFlow.

## 3. Organización de los componentes

Los componentes se agrupan según sus principales responsabilidades:

- **Interfaz de usuario:** Gestiona las pantallas y la interacción con los usuarios.
- **Lógica de negocio:** Implementa las funcionalidades y reglas del sistema.
- **Acceso a datos:** Permite consultar, almacenar y modificar la información en la base de datos.
- **Componentes transversales:** Gestionan funcionalidades compartidas, como las sesiones y las utilidades.

## 4. Relaciones entre componentes

El diagrama representa las dependencias entre los componentes y cómo colaboran para ejecutar las diferentes funcionalidades de GastroFlow.

Aunque los componentes se encuentran agrupados por responsabilidad, la implementación no sigue una separación estricta por capas.

## 5. Conclusión

El diagrama C4 de Nivel 3 permite visualizar la estructura interna de GastroFlow, facilitando la comprensión de sus componentes, responsabilidades y dependencias.
